고료별 가이드라인 링크

인플루언서에게 맞는 고료의 링크를 보내주세요. 링크 안에서는 고료가 보이지 않고, 허브로 돌아오는 길도 없어요.

HOW TO

운영 방법

  1. 고료 금액은 구글 시트 '고료표' 탭에만 적어요. 페이지 코드·구간·최소/최대 팔로워·고료를 맞춰두면, 지원서에 고료가 자동으로 붙어요.
  2. 지원자가 적은 팔로워 수가 링크의 구간과 다르면 시트 '확인' 칸에 표시돼요. 다른 구간 링크로 지원한 경우를 걸러낼 수 있어요.
  3. 고료 페이지 추가·변경: 목록은 암호화돼 있어서 파일에서 직접 고칠 수 없어요. Claude에게 요청하고, 시트 '고료표'에도 같은 코드를 넣어주세요.
  4. 브랜드 추가: 가이드라인 파일(index.html)의 ALL_BRANDS에 블록 하나를 추가하세요.
{
  id: 'brand',            // 영문, 필수
  name: 'BRAND',          // 필수
  summary: '한 줄 소개',   // 필수
  type: '릴스 20초 이상',  // 필수
  account: '@brand_official',
  hashtags: '#광고 #브랜드',
  // 선택 — 비우면 기본값
  make: [], upload: [],   // → "별도 가이드로 전달 예정입니다."
  reels: ['', ''],        // 레퍼런스 영상·이미지 경로
  reward: '제품',          // ※ 금액 적지 않기 (공개됨)
  quota: '10명', deadline: '11.30 마감',
  tiers: ['코드', '코드'],  // 위 카드의 페이지 코드. 이 링크에서만 노출, 없으면 전체
}
